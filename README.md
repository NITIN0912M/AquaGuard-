# 💧 AquaGuard - Smart Acoustic Leak Detection & Water Conservation Intelligence

AquaGuard is an IoT-powered telemetry and conservation dashboard that mitigates residential & commercial water loss through continuous acoustic leak detection, automated solenoid isolation, and Gemini AI-driven conservation audits.

## 🚀 Live Prototype
[Live Demo Link](https://agent-6a96ddbf646c66833--starlit-vacherin-1fc5d0.netlify.app)

## ✨ Core Features
- **Real-Time Diurnal Telemetry**: Live flow rates (L/min), pressure (PSI), tank level monitoring, and auto-pump triggers.
- **Acoustic Leak Detection & Triage**: Interactive sandbox simulating pipe bursts, toilet flapper bleeds, micro-drips, and irrigation valve jams.
- **Automated Emergency Isolation**: Remote 1-click & auto-lockout solenoid valve control to prevent structural flooding.
- **Zone-Level Sub-Metering**: Individual fixture isolation across bathrooms, kitchen, laundry, and garden.
- **Gemini 3.7 Flash Advisor**: Automated water audit reports, ROI/payback periods, and live conservation assistant chat.
- **Gamified Conservation Quests**: Community leaderboard, water impact calculator, and sustainability XP badges.

## 🛠️ Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Recharts, Lucide Icons
- **Backend / API**: Node.js, Express, Google GenAI SDK (`@google/genai`)
- **AI Model**: Gemini 3.7 Flash
